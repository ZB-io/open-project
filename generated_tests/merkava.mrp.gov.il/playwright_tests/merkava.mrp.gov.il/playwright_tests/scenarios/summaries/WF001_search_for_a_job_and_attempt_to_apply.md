# Search for a Job and Attempt to Apply

> **Status**: Preview — awaiting worker execution for full scenario details

## Overview

| Field | Value |
|-------|-------|
| Workflow ID | WF001 |
| Feature Area | Job Search and Filtering |
| Priority | high |
| Goal | A user should be able to search for jobs, apply various filters, view the details of a specific job, and begin the application process. The scenario is complete when the user is presented with the government login page. |

## Navigation Hint

1. Navigate to https://merkava.mrp.gov.il/giusp/index.html#/search-results
2. Click the 'מיקום' (Location) filter button.
3. Select the 'ירושלים' (Jerusalem) checkbox.
4. Click the 'תחום' (Field) filter button.
5. Select the 'בריאות' (Health) checkbox.
6. Click the 'משרד' (Office) filter button.
7. Select the 'משרד הבריאות' (Ministry of Health) checkbox.
8. Click the 'פרטים נוספים' (More details) button on a job listing.
9. On the job details page, click the 'הגשת מועמדות' (Submit Application) button.
