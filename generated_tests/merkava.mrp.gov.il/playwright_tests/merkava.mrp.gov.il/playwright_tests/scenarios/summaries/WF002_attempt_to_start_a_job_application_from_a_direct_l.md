# Attempt to Start a Job Application from a Direct Link (Fails)

> **Status**: Preview — awaiting worker execution for full scenario details

## Overview

| Field | Value |
|-------|-------|
| Workflow ID | WF002 |
| Feature Area | Job Application Submission |
| Priority | high |
| Goal | A user navigating directly to a job posting should be able to start the application process. The test will verify if the application form loads. Success: The application form loads. Failure: The page times out or shows an error. |

## Navigation Hint

1. Navigate to a specific job page, e.g., https://merkava.mrp.gov.il/giusp/index.html#/position/07378533
2. Click the 'הגשת מועמדות' (Submit Application) button.
3. Observe that the page times out and becomes blank, blocking the application process.
