# Submit an Inquiry via the User Support Form

> **Status**: Preview — awaiting worker execution for full scenario details

## Overview

| Field | Value |
|-------|-------|
| Workflow ID | WF003 |
| Feature Area | User Support and Contact |
| Priority | low |
| Goal | A user should be able to open the support modal, navigate to the online inquiry form, fill in all required fields, and submit the form. The test checks if the form can be submitted. |

## Navigation Hint

1. Navigate to https://merkava.mrp.gov.il/giusp/index.html#
2. Click the 'כאן בשבילכם' (Here for you) support button.
3. Click the 'פנייה מקוונת' (Online Inquiry) button.
4. In the new tab, select 'בקשה למידע' (Request for information) from the 'נושא ראשי' (Main Subject) dropdown.
5. Select 'בירור סטטוס' (Status inquiry) from the 'נושא משני' (Secondary Subject) dropdown.
6. Fill the 'פרטי הפנייה' (Inquiry details) with 'Test inquiry details'.
7. Fill the 'שם פרטי' (First name) with 'Test'.
8. Fill the 'שם משפחה' (Last name) with 'User'.
9. Fill the 'תעודת זהות' (ID card) with '123456789'.
10. Fill the 'טלפון' (Phone) with '0501234567'.
11. Fill the 'דוא"ל' (Email) with 'test@example.com'.
12. Check the confirmation checkbox 'למיטב ידיעתי הפרטים שמסרתי בטופס זה נכונים.'
13. Click the 'שליחה' (Send) button.
